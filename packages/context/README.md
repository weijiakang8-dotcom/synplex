# 项目背景整理

`prepareContext`使用真实scoped repo，不调用模型，不执行任务。目标、约束、验收逐字保留；当前已确认事实/决定/失败/有条件经验与候选、历史否决分开。指定资料精确过滤，原文指令不变成权限；结束前复核状态与权限。纯准备不写库，由服务注册不可变包及幂等回执。

预算采用UTF-8字节保守上界，包含包结构与引用，另保留512。它是有意偏保守的预算门，不是厂商tokenizer或收费测量。已确认必要信息容纳不下时明确budget_exceeded，不能截断目标。可选材料按完整单元加入，省略说明和原件保留；历史关键词检索有限且如实标partial，不宣称已理解所有转折。当前筛选是规则和人工选择，不是假装已有语义召回或自动推断替代关系。

测试涵盖HTTP真实准备/审核链路、否决历史、指定来源、低预算、原文完整、权限和版本失效。后续索引、大库分页成本和对真实项目的召回收益需另测。
