# 连接常用 AI 工具

Synplex 扩展的作用是把项目依据交给你正在使用的工具，并把结果记回项目。它不接管宿主的全部执行或全部账单。

## 网页下载

在“扩展”选择 Codex 或 DeepSeek Harness，下载当前项目的连接包。连接包绑定本机地址、准确项目和私有凭据文件路径，只供自己的电脑使用，不应公开上传。安装后按扩展说明调用项目工具。

## 从源码打包

先启动本机工作台。构建不带私人连接的公开包：

```sh
npm run build:codex
node plugins/build-dsh.mjs /absolute/path/to/new-dsh-package
```

目标必须是全新目录。配置连接时，使用数据目录内真实的连接信息，格式见 [DSH 桥说明](../adapters/dsh/README.md)及 `plugins/build-codex.mjs`。正式密钥正文不会写入包，只有本机文件路径；个人配置包仍不适合公开。

## 工具与责任

提供项目状态、查找依据、准备任务、记录结果、提出经验和核对回执六项工具。经验需要人工确认，来源材料不是操作授权。执行仍由当前宿主决定并完成；没有配置工作台受托执行器时，不会暗中启动第二个 Agent。

宿主运行时兼容性、原问题恢复与版本边界见[当前使用范围](LIMITATIONS.md)。不要把安装包存在等同于所有桌面版本都已验收。

## 成果文件回到工作台

扩展调用 `record_result` 时，可通过可选的 `artifactFiles` 一并接回真实文件，填写对应的 `artifactId` 和文件内容的 `base64`。每次文件合计不超过 1 MiB，仍受工具请求 2 MiB 上限约束；工作台逐份核对回执中的大小和 SHA-256。超限文件须拆分或通过工作台既有上传入口核对，不会自动读取宿主的路径或网址。

回执与文件在同一事务保存。连接中断后使用原请求核对或重试，不能换身份重新执行任务。文件可下载不代表已经符合业务要求，用户验收仍单独记录。
