# 当前使用范围

这里集中说明选择与使用产品时需要了解的边界。

## 平台与运行方式

本版本以个人本机工作台为主要使用方式，macOS 为主要验收平台。公网部署需独立认证、HTTPS、私有持久化存储与备份；不能把一个本机 owner 的资料库作为匿名公共空间。团队账号、租户调度和组织权限不在当前融合工作台的交付范围。

## 模型与宿主

模型目录不等于当前账号能够调用所有型号。真实可用范围由配置的执行器、供应商账号和余额决定。Codex / DeepSeek Harness 扩展有隔离运行时验证；不同桌面版本、自动选择工具及宿主原问题在重启后的恢复需要按实际版本核验。

## 文件与检索

PDF、Word、表格与幻灯片以提取可读内容为主，不重建所有原版式。受损、加密或超过限制的材料可能需要转换；原件仍保留。关键词索引和资料节选不等于全量语义理解。代码工具只执行受限小函数，不是任意项目的通用沙箱。

## 中断与恢复

备份恢复保留原记录，执行默认停用。首次闲置且无未知任务、积压消息的联合接管有专门核对路径；有未完成任务、原远端身份变化或跨引擎版本时，需要进一步核对，不能自动重发。Mac 真实中文输入法候选的完整人工验收仍待完成。

## 效益与真实用户反馈

功能、接口和故障回归已有工程检查；复杂任务质量、合格交付成本、真实账单、长期负载和非技术用户的上手体验仍需更多真实使用数据。预计费用不替代实付，尚不承诺固定节省比例或任意任务的完成率。
