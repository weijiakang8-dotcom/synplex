# 连接自己的模型

## 从列表选择，不必记型号

1. 打开 **任务 → 模型设置 → 添加模型**。
2. 给连接起一个方便辨认的名称，填写服务商提供的服务地址和访问密钥。密钥只填此处，不发到聊天、截图或问题反馈。
3. 点击 **保存连接**。系统查询账号开放的型号列表，不生成回复；也可先点击“获取可用型号”预览列表。
4. 回到对话输入框或执行任务，随时选择连接、型号和思考程度。所选内容进入真正请求，不暗中改用另一份连接。

通常只需名称、服务地址、密钥三项。服务商没有型号列表，或需要调整能力时，再展开“型号与能力（可选）”。官方已核对的 DeepSeek 型号使用对应能力配置；其他型号不按名字猜测工具或思考能力，可按服务商说明调整。型号列表可能包含非文字型号，列出不代表当前协议可调用。

**默认模型**由站点维护者提供，已登录账号均可选择，密钥不会返回网页，普通账号不能修改或停用平台默认连接。**我的模型**仅当前账号可用，可以不用默认模型。账号自己的“工作台内的用户”连接不会因此变成全站默认；全站默认只来自服务启动时固定的原所有者身份。

## 地址与连接方式

当前开放兼容 Chat Completions、Responses 的 HTTPS 服务。填写服务商提供的基础地址，例如 `https://api.example.com/v1`；不要填写网页后台地址、密钥参数或最终 `/chat/completions` 请求路径。只允许公开的安全地址，不能连接本机、私网或重定向目标。

DeepSeek 官方连接可填写 `https://api.deepseek.com`，查询使用其官方 `/models` 入口。点击“获取可用型号”只读取账号开放的型号，不生成回复；保存后仍需按服务商说明核对工具和思考能力。

对于官方地址的 `deepseek-flash`，“不思考”实际发送关闭思考的选项；低、高、最高程度实际发送对应思考参数。没有指定程度时保留服务商默认值。对话、试用与执行使用同一参数转换，不把本规则套用到中转服务或其他型号；其他连接按其已配置能力和协议发送。

部分网络代理将域名解析为 `198.18.0.0/15` 内的虚拟地址。工作台不会直接放行该地址：仅当系统返回的全部地址属于这一范围，且输入的是域名时，向固定的 Cloudflare `https://1.1.1.1/dns-query` 查询真实 IPv4 地址，然后重新检查公网范围并将连接固定到验证结果。DNS 查询仅包含服务域名，不带密钥、接口路径、消息或资料；不修改系统／代理设置，不重定向，不重试模型请求。私网、混合公网／非公网结果、直接填写虚拟 IP 仍被拒绝。真实地址确认失败时给出网络提示，不能通过关闭安全检查解决。

查询失败会区分密钥或权限、服务地址、请求限制、网络和返回格式；不会再统一提示“连接其他工具”。错误文案来自固定安全列表，不透传服务商错误正文或密钥。代理网络分支参考 [Mihomo DNS 配置](https://wiki.metacubex.one/config/dns/) 与 [Cloudflare DNS JSON 查询](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)，DeepSeek 型号入口见[官方文档](https://api-docs.deepseek.com/api/list-models)。

“更多设置”中的“通用对话”对应 Chat Completions，“新版对话”对应 Responses；以服务商文档为准，不按型号名字猜。账号中可能同时列出绘图、语音或其他型号，列出不代表当前聊天／执行协议能够调用。不能调用时会保留原记录，不自动重试或改用另一个付费来源。

“试用一次”是明确的生成请求，可能产生费用。正常保存和获取型号不会自动开始试用。

修改已有连接时，不更换密钥可将密钥栏留空；查询型号也可以使用已存密钥，密钥不会返回浏览器。更换服务地址或连接方式必须重新填写，不能把旧密钥自动发送到新地址。有任务使用时仍须先核对结束，才能修改。

## 费用设置

费用可暂不填，不影响连接使用。需要比较安排时，展开型号下的“费用设置”，填写**自己账号实际适用**的输入、缓存输入、输出单价（美元／百万计费单位），来源和生效时间；中转服务、套餐价、官方价不能混用，其他币种请先按明确汇率换算并在来源里说明。

- **单轮参考**：按当前文字容量、每步一次请求和回复上限计算，工具说明、前置文件和后续交互尚未计入。
- **规划范围**：按每步最多24次、每次使用资料容量和回复上限计算，是规划假设，不是实际报价或强制消费限额。
- **按单价计算**：仅在服务商返回完整输入、输出与缓存用量，且请求当时有有效单价时计算。请求保存当时的价格，后来修改连接不会改写旧费用。
- **账单实付**：以真实账单和已有对账入口为准；缺少用量、价格或结算时保持未知。失败、停止及返工记录保留。

任务比较页的型号安排会改变尚未开始的步骤；已提交的步骤和历史成果不会重新执行。完成时间和质量没有足够实测时不会给出虚构排名。

## 连接占用与备份

有任务使用时不能直接改密钥、停用或删除连接。先核对原任务；终态任务的模型回复未知时，可在用量区域保留待核对记录并解除占用，费用继续未知，原请求不重发。

密钥使用工作台独立主密钥加密。备份必须同时保全数据库、原件、配置及安全资料，存放在仅本人可读的目录；不能只复制数据库，也不能公开上传备份。不要手工补造主密钥或覆盖不完整恢复标记。

### 回复长度与文件生成

每次回复上限同时包含模型思考、工具参数和最终文字。长文档的工具参数也占回复容量；应根据正文长度和服务商能力设置，不能仅按屏幕上最终回复的长度判断。执行工作进程使用所选上限，并按同一上限预留预算；不会把16384悄悄压回4096。这只是上限，费用按实际用量计算。已有连接保留原值，不会在升级时偷偷提高。服务商明确报告长度用尽时，已收到的回复和用量仍保留，同一任务不再继续付费尝试。到“模型设置”调高上限后，基于保留的原任务准备修改；原失败和费用不会抹去。

单一格式文档明确导出后，工作进程可把通过归属和指纹核对的实际正文直接交给原成果核对流程，省去额外的模型收尾。文件存在不等于任务合格；核对失败、预算不足和人工验收仍独立保留。多格式或格式不明确的任务不采用这个提前结束路径。

### 维护者核对执行限额

自有执行引擎另有月度限额，初始为200000 token和5元参考费用；它与服务商余额、单次回复上限是不同的限制。遇到执行开始即停止，先看引擎日志及原任务记录，不要反复提交。

使用本产品的Python环境运行 `scripts/runtime/configure-execution-budget.py --engine /path/to/private-engine` 可查看原私人执行组织的限额与计数。经预算负责人授权后，可附加 `--tokens 1000000 --cost-cny 20` 设置明确上限；不清空用量、不放开并发、不发送模型请求。变更前后和提交意图保存在引擎私人目录，随联合备份保全。此工具不批量修改其他租户，也不代表服务商有相应余额。参考费用为引擎预算计数，不能当成账单实付；未知价格仍需另行对账。
