# 使用指南

## 从一个真实问题开始

例如：“上次修改了导出方案，但我忘了为什么；现在要交给另一款 AI 接着做。”

1. **新建项目**：用你平常叫它的名字。
2. **添加资料**：粘贴文字，或导入文档、表格、幻灯片、会话记录。原文件会保留。
3. **核对记录**：确认真实决定和有用经验；不准确的内容可以修改或不采用。
4. **新建任务**：写清想得到什么、哪些要求不能变、怎样算做完，选择有关资料。
5. **选择做法**：在工作台配置的执行工具中执行，或者下载扩展让当前工具接续。
6. **查看成果**：预览、下载并核对；需要调整时使用“修改成果”，保留前版。
7. **下次继续**：从项目页回看决定、问题和变化经过，不必重讲全部历史。

## 页面怎么用

| 页面 | 什么时候打开 |
|---|---|
| 项目 | 看当前决定、问题和整体状态 |
| 任务 | 准备工作、开始执行、补充回答和修改要求 |
| 资料 | 添加原件、分类、标签、锁定和查原文 |
| 记录 | 看决定与经验，编辑、比较版本和查看变化经过 |
| 成果 | 看已保存的交付文件、版本及核对结果 |
| 待核对 | 处理候选记录、冲突和需要本人判断的内容 |
| 扩展 | 下载当前项目连接包，把依据接到常用工具 |

点击“原文”可以回到依据；“版本”保留修改前后内容；“变化经过”解释有记录的修改原因和当前结论。系统不会编造没有记录的原因。

## 等待、失败和中断

- **等你回答**：回答当前问题，核对送达结果后继续。
- **需要确认**：查看具体操作与参数，再决定允许还是拒绝。
- **结果不确定**：先核对原任务回执；不要用新任务代替原任务重发。
- **成果需要修改**：提出明确修改要求，系统保留前版和验收条件。
- **连接失效**：刷新本机入口即可；不需要重发任务。

## 费用怎么读

预计费用是规划参考，已知用量来自实际回执，账单金额以供应商账单为准。未知费用保持未知，失败与返工也保留记录。扩展不能统计宿主在 Synplex 之外的全部消费。

## 保护自己的资料

先使用可公开或已脱敏的材料熟悉流程；向模型发送前检查选中的资料。只有明确选择公开的项目介绍才应对外分享，普通项目记录不会自动公开。
