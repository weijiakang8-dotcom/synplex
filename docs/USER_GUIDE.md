# 使用指南

## 从一个真实问题开始

例如：“上次修改了导出方案，但我忘了为什么；现在要交给另一款 AI 接着做。”

1. **新建项目**：用你平常叫它的名字。
2. **添加资料**：粘贴文字，或导入文档、表格、幻灯片、会话记录。原文件会保留。
3. **核对记录**：确认真实决定和有用经验；不准确的内容可以修改或不采用。
4. **新建任务**：写清想得到什么、哪些要求不能变、怎样算做完，选择有关资料。
5. **选择做法**：在工作台配置的执行工具中执行，或者下载扩展让当前工具接续。
6. **查看成果**：预览、下载并核对；需要调整时使用“修改成果”，保留前版。
7. **下次继续**：从项目页回看决定、问题和变化经过，不必重讲全部历史。

## 聊清楚，再开始执行

“任务”内可以切换 **对话／执行任务**。对话保留消息、模型选择和草稿；普通聊天不会声称已创建文件或操作外部系统。想要文件时，点击“带入执行”，把完整对话冻结为参考，补充具体要求后明确开始。对话回答只是参考，不自动成为已确认事实。

两种方式都可以打开“模型设置”，连接自己的账号或使用管理员提供的内置模型。无需记住型号，填写地址与密钥后点击“获取可用型号”。详细步骤见[模型连接](MODELS.md)。

## 页面怎么用

左侧按项目展开工作和资料，中央标签页切换功能，右侧显示当前任务进度或相关背景。宽屏可拖动分隔线调整两侧宽度；窄屏自动改为上下排列。任务入口默认打开对话，也可从导航直接进入“执行任务”。已打开的对话有独立标签，未发送的草稿随对话保留；切换项目不混用草稿。

| 页面 | 什么时候打开 |
|---|---|
| 项目 | 看当前决定、问题和整体状态 |
| 任务 | 准备工作、开始执行、补充回答和修改要求 |
| 资料 | 添加原件、分类、标签、锁定和查原文 |
| 记录 | 看决定与经验，编辑、比较版本和查看变化经过 |
| 成果 | 看已保存的交付文件、版本及核对结果 |
| 待核对 | 处理候选记录、冲突和需要本人判断的内容 |
| 扩展 | 下载当前项目连接包，把依据接到常用工具 |

点击“原文”可以回到依据；“版本”保留修改前后内容；“变化经过”解释有记录的修改原因和当前结论。系统不会编造没有记录的原因。

## 导入 Obsidian 笔记

在左侧点击 **Obsidian 笔记库**，或在“资料”点击 **导入笔记库**。首次点击“连接笔记库”，选择文件夹；之后点击“读取已连接的笔记库”，即可查找、勾选文档并导入当前项目。浏览器会记住文件夹连接，刷新后不必重新寻找原目录；权限过期时按提示重新允许读取。

- 只有勾选的 Markdown 笔记会上传。原库、原文字节、换行和原来的链接均不修改，不会上传 `.obsidian` 设置或隐藏文件。
- 每篇最多2兆；按文件逐篇导入，列表分页面展示。单次扫描最多列出10000篇笔记、检查50000个条目和40层目录；达到上限明确提示，不悄悄省略。建议先选与当前任务有关的笔记，再逐步补充。
- “查看内容”中的 **笔记链接** 可打开同库内已导入的文档；保留别名和段落名称。没有导入的目标会提示补充，同名目标会提示选择，不会猜测或打开外部程序。
- 再次选择同一笔记库时保持名称一致。未变化的笔记跳过；变化的原件另存，旧记录保留。锁定资料不会被导入覆盖。笔记库原文不会因产品内的分类或编辑而被写回。
- 导入只生成待核对记录。确认、修改或不采用后，才形成你认可的项目记忆。没有记录的转向原因不会自动补造。
- 保存结果不明时，重新选择同一篇可核对原提交；不要改名重复导入。换设备后仍应先核对“资料”中的原文件与处理进度。

## 等待、失败和中断

- **等你回答**：回答当前问题，核对送达结果后继续。
- **需要确认**：查看具体操作与参数，再决定允许还是拒绝。
- **结果不确定**：先核对原任务回执；不要用新任务代替原任务重发。
- **成果需要修改**：提出明确修改要求，系统保留前版和验收条件。
- **连接失效**：刷新本机入口即可；不需要重发任务。

## 费用怎么读

预计费用是规划参考，已知用量来自实际回执，账单金额以供应商账单为准。未知费用保持未知，失败与返工也保留记录。扩展不能统计宿主在 Synplex 之外的全部消费。

## 保护自己的资料

先使用可公开或已脱敏的材料熟悉流程；向模型发送前检查选中的资料。只有明确选择公开的项目介绍才应对外分享，普通项目记录不会自动公开。

## 使用邮箱账号

打开工作台后，用登录名或邮箱和密码登录。没有账号则点击“注册”，设置登录名、获取邮件验证码、设置密码后进入自己的项目；无需寻找连接码。邮件尚未设置时会明确提示，请由网站维护者按[账号指南](ACCOUNTS.md)完成配置。原主人从私人启动入口可选择“绑定邮箱”带入已有项目。

已有账号可在侧栏“账号设置”中设置登录名。忘记密码时，在登录页点“忘记密码？”，用注册邮箱收取验证码后设置新密码；成功后其他已登录网页也需要重新登录，原项目和资料保留。

笔记库文件夹连接仅保存在当前浏览器与当前账号中，不上传整个目录；“断开连接”只移除本浏览器的引用，既不删除原笔记，也不删除已导入资料。不支持持久文件夹权限的浏览器可展开“其他导入方式”临时选择文件夹或文件。
